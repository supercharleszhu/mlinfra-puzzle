# Official Triton notebook snapshots

Days 01-10 were downloaded from the notebook links at the bottom of the
corresponding pages in the official
[Triton tutorial gallery](https://triton-lang.org/main/getting-started/tutorials/).
Day 11 was converted without code changes from Triton's official
[`11-programmatic-dependent-launch.py`](https://github.com/triton-lang/triton/blob/main/python/tutorials/11-programmatic-dependent-launch.py)
because its current website notebook download is unavailable.

These files are immutable inputs to `../scripts/generate_notebooks.py`. The
generated lesson notebooks preserve their cells, clear execution state, and
append the local challenge cells. See `LICENSE.triton` for the upstream license.
